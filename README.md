<h1>Hi, I'm Aditya Singh</h1>

**AI Engineer at [Optivaize](https://optivaize.nl)**, a Dutch AI agency. I build AI agents, automations and full-stack apps that run in production for e-commerce and B2B clients.

I'm also available for freelance work on [Upwork](https://www.upwork.com/freelancers/~0110adb323ff99945b).

### What I work on

- **AI agents and chatbots**: tool calling, RAG over company docs, human handoff, evaluation
- **Business automation**: syncing data between Shopify, ERPs, CRMs, accounting tools and dashboards
- **Document AI**: OCR, structured extraction, validation, generated reports
- **Full-stack apps**: FastAPI / Django backends, React + TypeScript front ends, Postgres, Docker, AWS

### Recent client work (private repos)

- ERP to Shopify connector: order, stock and fulfilment sync across 3 live stores, with failure alerts
- Finance dashboard: daily accounting API sync into Postgres, payment prediction and debtor risk scoring, Power BI
- AI pipeline that generated and published 540+ product 3D/AR models to a live Shopify store
- Client platform for managing AI agents, and a customer support chatbot for a webshop
